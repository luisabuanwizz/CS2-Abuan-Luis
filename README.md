# Travel Fare Calculator

## Description
This program calculates the fare based on the total fare rate, amount of passengers, and distance.

## Version 1 - Original code without input validation

- Input: Accepts a name, distance of travel, and passengers.
- Process: Calculates and shows to user their name and price of fare.
- Output: Name & Total Fare
- Doesn't have input validation.

## Version 2 - Updated code with working input validation

- Input: Accepts a name, distance of travel, and passengers.
- Process: Calculates and shows to user their name and price of fare.
- Output: Name & Total Fare
- Has input validation and gives user a second try before asking
